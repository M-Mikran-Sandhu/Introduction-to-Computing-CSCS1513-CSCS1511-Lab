# Array Statistics

## What it does
Reads up to 50 integers into an array, then prints the sum, minimum, maximum and average.

## Concepts used
1D arrays, array indexing (starts at 0), loops over arrays, type casting `(double)`, input validation

## Sample run
```
How many numbers (1 to 50)? 3
Enter number 1: 4
Enter number 2: 9
Enter number 3: 2

Numbers: 4 9 2 
Sum: 15
Minimum: 2
Maximum: 9
Average: 5
```

## What I learned
Used Type cast and how we can make temporary copy of one type of variable to other.
