# Introduction to Computing (CSCS1513 + CSCS1511 Lab), C++

First programming course at the University of Central Punjab (UCP), Gujranwala.
Part of my [UCP CS Journey](https://github.com/M-Mikran-Sandhu/ucp-cs-journey).

> My original coursework was not saved, so these are revision programs I wrote
> in 2026 to rebuild and document what the course taught.

## Topics covered
- Program structure, variables, data types, `cin` / `cout`
- Operators and expressions
- Decisions: `if`, `else if`, `else`, `switch`
- Loops: `for`, nested loops
- Functions
- 1D and 2D arrays
- Strings

Pointers and references are taught in the next course, so they are covered in that course's repository.
