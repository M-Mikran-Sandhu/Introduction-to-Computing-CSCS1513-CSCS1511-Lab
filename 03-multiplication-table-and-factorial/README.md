# Multiplication Table and Factorial

## What it does
Prints the multiplication table (1 to 10) of a number, then computes the factorial of a number from 0 to 12.

## Concepts used
`for` loops, accumulator variable, `int`, input validation (`if` / `else`, `||`)

## Sample run
```
Enter a number for its multiplication table: 5
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50
Enter a number for its factorial (0 to 12): 5
5! = 120
```

## Note
Factorials above 12! are too big for a normal `int`, so the program only accepts 0 to 12.
