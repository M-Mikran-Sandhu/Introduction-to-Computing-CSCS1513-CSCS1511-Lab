# Matrix Operations

## What it does
Reads two matrices of the same size (up to 5 x 5), then prints their sum and the transpose of the first matrix.

## Concepts used
2D arrays, nested `for` loops, row and column indexing, input validation

## Sample run (2 x 3)
```
Enter number of rows (1 to 5): 2
Enter number of columns (1 to 5): 3

Enter elements of matrix A:
A[0][0]: 1
A[0][1]: 2
A[0][2]: 3
A[1][0]: 4
A[1][1]: 5
A[1][2]: 6

Enter elements of matrix B:
B[0][0]: 1
B[0][1]: 1
B[0][2]: 1
B[1][0]: 1
B[1][1]: 1
B[1][2]: 1

A + B:
2	3	4	
5	6	7	

Transpose of A:
1	4	
2	5	
3	6	
```

## What I learned
The rows and column can be interchanged to get the transpose of the matrix
