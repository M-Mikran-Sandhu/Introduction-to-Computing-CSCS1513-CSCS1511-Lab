# Even/Odd and Grade Calculator

## What it does
Tells whether an integer is even or odd, then converts marks (0-100) to a letter grade. Rejects marks outside 0-100.

## Concepts used
`if` / `else if` / `else`, `%` operator, logical OR (`||`), input validation

## Sample run
```
Enter an integer: 7
7 is odd.
Enter your marks (0-100): 85
Grade: B
```

## Note
Grade boundaries (90/80/70/60) are a generic scale, not UCP's official grading.
