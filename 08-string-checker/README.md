# String Checker

## What it does
Reads a line of text, counts its vowels and consonants, and checks whether the letters form a palindrome (ignoring case, spaces and punctuation).

## Concepts used
`string`, `getline`, `length()`, character indexing, `tolower`, `isalpha`, `bool` flag, loops

## Sample run
```
Enter a word or sentence: Madam
Vowels: 2
Consonants: 3
It is a palindrome.
```
