# Simple Calculator

## What it does
Reads two numbers and an operator, then prints the result. Rejects division by zero and invalid operators.

## Concepts used
Variables, `cin` / `cout`, `switch`, `if` / `else`,`Goto`

## Sample run
```
Enter first number: 12
Enter second number: 4
Enter operator (+, -, *, /): /

12 / 4 = 3
```

## What I learned
In the making of a simple calculator a small error of divided by zero can effect the whole programs reliability
