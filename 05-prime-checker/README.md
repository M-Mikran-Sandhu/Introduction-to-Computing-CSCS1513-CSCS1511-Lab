# Prime Number Checker

## What it does
Checks whether a number is prime, then prints all primes up to a limit.

## Concepts used
Functions (`bool` return type, parameter, `return`), `for` loops, `%` operator

## Sample run
```
Enter a number: 7
7 is a prime number.
Print all primes up to: 20
Primes: 2 3 5 7 11 13 17 19
```
